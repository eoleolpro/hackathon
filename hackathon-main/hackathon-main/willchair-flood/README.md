# WILLCHAIR RESCUE MVP

휠체어 사용자를 위한 **위치 확인 → 지도 → 단일 시점 위치 공유** 프론트엔드입니다.
구명조끼 보관 상태는 센서 없는 테스트 시뮬레이션이며, 실제 착용 여부는 미확인입니다.

## 설치·실행

Node.js `^20.19.0 || >=22.12.0` 환경에서 실행합니다.

```sh
npm ci
npm run dev
npm run build
npm run preview
npm run lint
npm run test:e2e
```

기본 개발 주소는 `http://localhost:5173/`입니다. 다른 포트가 표시되면 서버가 출력한 주소를 사용하세요.
좌표 수신에는 HTTPS와 사용자 권한이 필요합니다. 개발용 localhost는 예외입니다.
별도 백엔드·DB·로그인·API 키는 없습니다. 지도 타일에는 인터넷 연결이 필요합니다.

## 메인 화면

1. WILLCHAIR RESCUE 헤더
2. 구명조끼 연결·보관 상태 — 테스트 제어는 기본 접힘
3. 긴급 위치 모드 시작·종료
4. 현재 좌표·정확도·측정 시각·수신 상태
5. 실제 OpenStreetMap 지도·정확도 원·현재 위치로 이동
6. 현재 위치 공유·링크 복사
7. 119 전화 연결

민감한 위치·공유 메시지·연락처를 서버, localStorage, 분석 도구, 콘솔에 저장하지 않습니다.
지도 표시 지역의 타일 요청은 OpenStreetMap에 전달될 수 있음을 시작 전에 안내합니다.

## 동작과 한계

- 사용자가 시작할 때만 `watchPosition()`으로 권한을 요청합니다. 앱 로드나 분리 이벤트만으로 위치 수신을 시작하지 않습니다.
- 중복 시작은 무시합니다. 명시적 재요청은 이전 watch를 정리한 뒤 하나만 만듭니다.
- 종료·컴포넌트 해제·`pagehide`에서 `clearWatch()`를 호출하며, 늦은 콜백과 이전 측정 시각의 결과를 무시합니다.
- 60초 이상 지난 위치, 정확도 수치 100m 초과 시 주의 표시합니다. 이는 앱 표시 기준이며 실제 오차·안전성을 보장하지 않습니다.
- 화면 잠금·백그라운드에서 지속 추적을 보장하지 않습니다.
- 공유 메시지는 위도·경도·측정 시각·정확도·OSM 링크를 포함한 스냅샷입니다. 실시간 추적 링크가 아닙니다.
- Web Share를 우선 사용하고, 미지원·실패 시 **위치 링크 복사**를 제공합니다. 자동 복사도 안 되면 링크를 직접 선택할 수 있습니다.
- 전체 메시지는 접이식 미리보기에서 확인·복사합니다. 위치가 갱신돼도 기존 공유 스냅샷은 바뀌지 않습니다.
- 시스템 공유 절차 반환/취소/오류/복사는 구분하지만 전송·상대방 수신 완료로 표시하지 않습니다.
- 종료 시 현재 좌표·공유 상태를 비웁니다. 이미 공유된 정보, 클립보드, 브라우저 캐시는 회수할 수 없습니다.
- `tel:119`는 전화 앱만 엽니다. 자동 신고·신고 접수·구조기관 연계가 아닙니다. 정적 HTML 전화 안내는 앱 실행 실패 시에도 남습니다.
- 보관 상태는 STORED/REMOVED/DISCONNECTED/UNKNOWN입니다. 보관함 분리 이벤트는 사용자의 활성화 선택을 기다립니다.
- 실제 BLE 검색·연결·착용 감지는 없습니다. `DeviceEventAdapter`와 `MockDeviceControls` 계약을 따르는 MockDeviceAdapter만 사용합니다.
- 실제 안전 장비로 사용 가능한 제품이라는 주장을 하지 않습니다.

## 유지한 코드 구조

```text
src/
  App.tsx
  components/
    emergency/    핵심 화면·위치·공유·접이식 이용 안내
    device/       보관 상태·테스트 제어
    map/          Leaflet 지도·현재 위치·정확도 원·타일 상태·오류 경계
    common/       119 안내·앱 오류 경계
  hooks/          위치·공유·장치 이벤트·지도 타일 수명 관리
  services/       Geolocation·Web Share·Clipboard API
  adapters/       장치 이벤트 계약·MockDeviceAdapter
  types/          위치·공유·장치 타입
  utils/          시간·위치 품질·상태 표시
```

기존 위치/지도/공유 코드를 재사용했습니다. 경로 탐색·위험 계산·등시간선·침수 타임라인·대피 후보·Turf 의존성·GeoJSON 파일은 현재 코드와 배포물에서 제거했습니다.

## 브라우저 테스트

Playwright는 설치된 Chrome을 기본 사용합니다. 필요하면 `npx playwright install chromium` 후 `PLAYWRIGHT_CHANNEL=chromium`으로 실행하세요.
테스트용 localhost:5173 개발 서버가 없으면 자동으로 시작합니다.
`playwright-report/`에 결과, `test-results/`에 실패 trace·확인용 스크린샷을 생성합니다. 이 폴더는 Git에서 제외합니다.

테스트 위치는 Chrome 가상 좌표 또는 테스트 콜백입니다. 실제 개인 좌표를 수집하지 않으며, 공유·복사는 테스트 대체 구현으로 외부 전송 없이 확인합니다.
실제 스마트폰 GPS·OS 공유·119 통화가 검증된 것으로 해석하지 않습니다.

## 실제 스마트폰 검증 — 별도 수행 필요

1. HTTPS 테스트 주소를 휴대전화에서 엽니다. 컴퓨터의 `http://192.168...` 주소는 보안 컨텍스트가 아니므로 위치 수신이 제한될 수 있습니다.
2. 시작 전 권한 요청과 위치 마커가 없어야 합니다. 시작 버튼을 눌러 실제 권한 거부/허용을 각각 확인합니다.
3. 안전한 장소에서 좌표·정확도·갱신 시각·지도 마커를 확인하고, 현재 위치로 이동과 줌·이동을 시험합니다.
4. 60초 이상 새 위치가 없거나 수신 환경이 나쁘면 오래됨·정확도 안내를 확인합니다.
5. 공유 화면을 열고 취소합니다. 실제 전달 시험은 동의한 테스트 대상에게만 수행하고, 앱의 수신 미확인 표시가 유지되는지 확인합니다.
6. Web Share 미지원 환경에서 링크 복사와 수동 선택을 확인합니다. 테스트 후 클립보드는 사용자가 정리합니다.
7. 종료·페이지 이탈 후 관찰 중지, 마커·공유 내용 제거를 확인합니다. 잠금/복귀에서는 지속 갱신을 보장하지 않는다는 안내와 실제 측정 시각을 확인합니다.
8. 테스트 모드에서 분리·수납·끊김·미확인 이벤트와 사용자 수락 후 시작을 확인합니다. 실제 센서 연결이나 착용으로 해석하지 않습니다.
9. 119는 링크와 전화 앱 연결까지만 확인합니다. 시험 목적으로 실제 긴급 전화를 걸지 않습니다.
10. 실제 휴대전화의 터치·글자 확대·VoiceOver/TalkBack 사용성을 별도로 확인합니다.
