useFloodData, App, 지도·정보·경로 패널, 시나리오 설명, CSS와 README를 수정했습니다.

## 구현

각 시간에 수작업으로 지정한 좌표를 사용합니다. buffer, 지형 모델, 실제 기상·관측·예측 데이터는 사용하지 않습니다.
선택 시나리오와 시간으로 표시 Polygon을 결정하고, 같은 Polygon으로 지점 포함과 경로 중첩을 분석합니다.
시간 변경 시 경로 선택과 거리 정보는 유지됩니다. 후보 조건은 해당 시점의 가상 영역과 중첩하지 않는 사전 준비 우회 경로입니다.

전체 초기화: 0분, 평상시, 좌표 미선택, 선택 경로 해제, 출발지 지정 대상, 영역 표시 켜짐, 강남역 기본 지도.
시간별 데이터가 지형 기반 예측이 아니라는 문구는 접을 수 없는 고정 안내문과 타임라인·분석 시점에 표시합니다.

## 검증 결과

- npm run build 성공. 타입·컴파일 오류 없음.
- Chrome 1440px / 모바일 화면 390px에서 검증.
- 5개 프레임의 GeoJSON 유효성 및 시간 메타데이터 검사 통과.
- 시간 메타데이터가 잘못된 자료 거부 확인.
- 집중호우 기준 0분은 모두 중첩 없음, 15/30분은 일반 경로만 중첩, 45/60분은 모두 중첩 확인.
- 지도 Polygon의 실제 SVG 경로가 각 시간마다 변경됨을 확인.
- 경로 선택 유지, 분석 시점 표시, 우회 후보 실시간 변경 확인.
- 슬라이더 키보드 방향키, 시간 버튼 확인.
- 영역 숨김에도 시간별 분석 유지.
- 팝업이 현재 시점 설명을 표시하며 지도 지점 선택 동작 유지.
- 전체 초기화 후 좌표·경로 제거, 0분·평상시·표시 켜짐 확인.
- 초기화 후 시연 지점을 다시 선택하면 기본 일반 경로가 선택됨을 확인.
- 모바일 가로 넘침 없음, 스크롤 시 가상 데이터 안내 표시 확인.
- 브라우저 런타임 예외 없음.

실제 침수 안전 판정이나 예측 결과가 아닙니다.
