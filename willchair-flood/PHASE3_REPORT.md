## 직접 확인

1. npm run dev로 실행 후 집중호우 선택: 서측 파란 영역 1개.
2. 영역 내부 클릭: 설명 팝업과 출발지 포함 표시.
3. 영역 밖 클릭: 목적지 실제 안전 여부 미확인 표시.
4. 평상시 선택: 파란 영역이 사라지며 기존 출발지도 구역 밖·안전 미확인으로 변경.
5. 침수 발생 선택: 3개 영역 표시.
6. 표시 체크 해제: 영역이 사라지지만 포함 판정 유지.
7. 설정 초기화: 좌표 삭제, 평상시 및 표시 체크 복원.

모든 영역은 시뮬레이션이며 실제 침수·안전 정보가 아닙니다.
