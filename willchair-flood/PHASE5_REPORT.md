# 5단계 경로·침수 분석 보고

## 구현

- src/utils/routeAnalysis.ts: booleanIntersects 기반 경로별 중첩·구역 목록·후보 조건.
- src/components/RouteInformation.tsx: 거리·중첩·접근성 비교, 상세, 후보 선택 및 결과 없음.
- src/components/map/RouteLayer.tsx: 중첩 경로 붉은색 표시. 실선/점선 구분 유지.
- App, InteractiveMap, InformationPanel, CSS 및 README 연동.
- @turf/boolean-intersects 의존성 추가.

## 결과 해석

평상시에는 영역이 0개이므로 두 경로 모두 가상 중첩 없음으로 표시하고 우회 후보 1개를 제시합니다.
실제 안전은 미확인입니다. 집중호우에서는 출발점이 서측 가상 영역 안에 있어 두 경로 모두 위험 중첩이며 후보 결과 없음입니다.
침수 발생에서는 두 경로가 서측·동측 구역에 중첩됩니다. 후보를 임의 생성하지 않습니다.
모든 경로의 경사도·턱·보도 접근성은 미확인입니다.
