# WILLCHAIR FLOOD 품질 점검 보고

점검일: 2026-11-14 (KST)
환경: Windows, Node.js 26.13.0, 설치된 Chrome, Playwright, axe-core.
기존 지도·경로·침수·타임라인·가상 시간 범위·대피 후보 기능과 색상/레이아웃을 유지했습니다.

## 수정 사항

1. 상태·초기화·파생 분석을 `useDashboard`로 분리하고 App은 화면 조합을 담당하도록 정리했습니다.
2. `strict: true`를 적용하고 TypeScript 타입 오류를 수정했습니다.
3. 공통 파일 요청을 `readJson`으로 분리해 네트워크·HTTP·JSON 실패에 자료 이름을 표시합니다.
4. 지도 타일 상태를 분리했습니다. 성공 타일이 일부 실패를 덮지 않으며, 15초 응답 대기 시간 초과와 재시도를 지원합니다.
5. 지도 렌더 오류 경계로 다른 정보 패널과 상태를 보존하며 복구할 수 있도록 했습니다.
6. 지도 Enter로 중심 지점을 지정하고 방향키로 이동할 수 있습니다. 경로·침수 영역은 Tab 후 Enter/Space로 선택합니다.
7. 후보 마커의 Enter/Space 조작 시 팝업만 열리고 카드 선택이 갱신되지 않던 문제를 수정했습니다.
8. 위험 상태의 텍스트·접근 가능한 이름·툴팁을 제공하며 일반 실선/우회 점선을 유지합니다.
9. 출처·파일 수정 시각(KST) 표를 추가했습니다. 지도 원본 갱신 미확인, 마지막 타일 수신, 시뮬레이션 파일 수정 시각을 구분합니다.
10. 긴 정보 패널이 지도 높이를 과도하게 늘리던 문제를 수정했습니다. 데스크톱 540px, 모바일 410px로 고정합니다.
11. 본문 바로가기 포커스, 고정 안내문과 포커스 여백, 작은 화면 터치 영역 및 동작 감소 설정을 보완했습니다.
12. 설치·실행·테스트·출처·기능별 한계를 README에 정리했습니다.

## 산출물 및 재실행

- `e2e/quality.spec.ts`, `playwright.config.ts`: 재실행 가능한 회귀·접근성·오류 테스트.
- `playwright-report/index.html`: 마지막 전체 테스트 HTML 결과.
- `test-results/`: 스크린샷. 실패 시 trace도 저장합니다.
- `artifacts/quality/desktop.png`, `artifacts/quality/mobile.png`: 직접 확인한 화면 사본.
- `public/data/metadata.json`: 시뮬레이션 자료의 로컬 수정 시각.
- `scripts/update-data-metadata.mjs`: 수정 시각 생성기. 빌드 전 자동 실행.

생성된 브라우저 리포트·스크린샷은 Git에서 제외합니다. 재실행 방법은 README에 있습니다.

## 미검증 범위와 한계

- 실제 Android/iOS 기기, 실제 손가락 핀치 제스처, Safari·Firefox는 테스트하지 않았습니다.
- NVDA·VoiceOver 등 실제 스크린리더 청취 및 사람의 전체 키보드 사용성 평가는 수행하지 않았습니다.
- 자동 접근성 위반 0건은 접근성 인증이나 모든 사용자 경험의 보장을 뜻하지 않습니다.
- 클린 환경 재설치는 별도로 수행하지 않았습니다. 이번 환경에서 의존성 설치·빌드·실행을 확인했습니다.
- 경로·침수·등시간선·대피 후보는 시뮬레이션입니다. 실제 지형 예측·침수 안전·접근성·운영 여부를 검증하지 않았습니다.
- OpenRouteService 실제 API 통신은 구현·테스트하지 않았습니다. 제공자 인터페이스만 준비되어 있습니다.
